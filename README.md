# ডেলিভারি লোকেশন অ্যাপ (শেখার প্রজেক্ট)

গ্রাহক নাম লিখে "পরবর্তী" চাপে → ব্রাউজার লোকেশনের অনুমতি চায় → অনুমতি দিলে নাম ও লোকেশন সংরক্ষিত হয়।
অনুমতি না দিলে হাতে ঠিকানা লেখার বিকল্প আসে। Admin লগইন করে তালিকা দেখতে ও মুছতে পারে।

## ফোল্ডার

```
server.js          Express + SQLite ব্যাকএন্ড
public/index.html  গ্রাহকের পেজ (সবাই দেখতে পারে)
private/admin.html Admin পেজ (শুধু লগইন করলে)
data.db            চালানোর পর নিজে তৈরি হবে
```

## চালানোর নিয়ম (নিজের কম্পিউটারে)

Node.js ইনস্টল থাকতে হবে।

```bash
cd delivery-location-app
npm init -y
npm install express better-sqlite3
ADMIN_PASSWORD='একটা-শক্ত-পাসওয়ার্ড' node server.js
```

Windows (PowerShell):

```powershell
$env:ADMIN_PASSWORD="একটা-শক্ত-পাসওয়ার্ড"; node server.js
```

- গ্রাহক পেজ: http://localhost:3000
- Admin: http://localhost:3000/admin (ইউজার `admin`, পাসওয়ার্ড আপনার দেওয়াটা)

`localhost`-এ HTTPS ছাড়াই লোকেশন কাজ করে। ফোনে টেস্ট করতে হলে HTTPS লাগবে (নিচে দেখুন)।

## HTTPS-এ হোস্ট করা

Render, Railway বা Fly.io-তে GitHub থেকে ডিপ্লয় করলে ফ্রি HTTPS পাওয়া যায়।
- `ADMIN_PASSWORD` প্ল্যাটফর্মের Environment Variables-এ সেট করুন, কোডে লিখবেন না।
- সাবধান: বেশিরভাগ ফ্রি হোস্টিংয়ে ফাইল রিস্টার্টে মুছে যায়, তাই `data.db`-ও হারাতে পারে। স্থায়ী ডিস্ক বা PostgreSQL ব্যবহার করুন।
- Admin-এর Basic লগইন শুধু HTTPS-এ ব্যবহার করুন।

## যা শিখছেন

1. Geolocation API আর permission flow (`public/index.html`)
2. ব্রাউজার থেকে `fetch` দিয়ে সার্ভারে ডেটা পাঠানো
3. Express API, ইনপুট ভ্যালিডেশন, SQLite (`server.js`)
4. Admin সুরক্ষা: পাসওয়ার্ড, `timingSafeEqual`, XSS এড়াতে `textContent`
5. গোপনীয়তার নিয়ম: কারণ জানানো, সম্মতি, বিকল্প পথ, ডেটা মুছে ফেলার সুযোগ

## নিয়ম মেনে চলুন

- এই পেজ শুধু সেই গ্রাহককে দিন, যে সত্যিই আপনার কাছে অর্ডার বা ডেলিভারি চায়।
- অন্য কাজের ভান করে (পার্সেল ট্র্যাক, পুরস্কার ইত্যাদি) লিংক পাঠিয়ে কারও লোকেশন নেওয়া প্রতারণা ও অপরাধ।
- যতটুকু দরকার ততটুকুই রাখুন, আর কাজ শেষ হলে মুছে দিন।

## পরের ধাপ
